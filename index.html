怎么免费用起来（手机+电脑互通）
1）本应用是纯前端网页，单个 index.html 即可运行。
2）手机电脑互通：在「我的」开启云端同步，填入免费的 GitHub Token（GitHub→Settings→Developer settings→Personal access tokens，勾 repo 与 gist），数据会自动存到你的 Gist，任何设备登录同一账号即同步。
3）免费部署：把 index.html 推到 GitHub 仓库并开启 Pages，或用 Cloudflare Pages / Vercel 拖拽上传，得到 https 网址。手机浏览器打开后「添加到主屏幕」，即是一个 App 图标。
4）不注册账号也能用：数据存在本机浏览器；换设备时用「导出/导入」迁移。
